# XOC-128 / 1x OPG-128 -- Clos SH (Liquid-Cooled, 8-Server Unit)

This is the liquid-cooled variant of the single-homed OPG-128 XOC-128 composition. It is topologically identical to the air-cooled counterpart; only the cooling medium and rack density differ (not modeled in DIET). Wiring CRDs and topology diagrams are cloned from the air-cooled composition.

Attributes
- Backend: single-homed Clos
- Scale-out NICs: CX7 1x400G per GPU
- Frontend NICs: BF3 2x200G per server (L3MH)
- Storage: converged, 2x200G per server
- Cooling: liquid (direct liquid cooling, 8-server unit)

Assets present here
- `connectivity-map.csv` -- end-to-end device and port mapping (generated by DIET pipeline)
- `wiring/wiring-backend.yaml` -- backend fabric wiring CRDs (cloned from air variant)
- `wiring/wiring-frontend.yaml` -- frontend fabric wiring CRDs (cloned from air variant)
- `diagrams/hhfab/backend.drawio` -- backend topology diagram (cloned from air variant)
- `diagrams/hhfab/frontend.drawio` -- frontend topology diagram (cloned from air variant)
- `netbox_inventory.json` -- NetBox inventory export

Notes
- Wiring topology is identical to the air-cooled variant. This directory carries its own generated artifacts for catalog completeness, not because the design differs.
- The `--liquid-8srv` suffix identifies liquid-cooled variants with an 8-server-per-unit rack density.
