# XOC-512 / 1x OPG-512 -- Rail-Optimized Clos (Liquid-Cooled, 8-Server Unit)

This is the liquid-cooled variant of the XOC-512 1x OPG-512 rail-optimized Clos composition. It is topologically identical to the air-cooled counterpart; only the cooling medium and rack density differ (not modeled in DIET). Wiring CRDs and topology diagrams are cloned from the air-cooled composition.

## Composition attributes

| Attribute | Value |
|-----------|-------|
| Total xPUs | 512 (64 servers × 8 xPUs) |
| Backend topology | Rail-optimized Clos (single OPG-512 unit) |
| Scale-out NICs | CX7 1×400G per GPU |
| Frontend NICs | BF3 2×200G per server (L3MH) |
| Cooling | Liquid (direct liquid cooling, 8-server unit) |

## Assets present here

- `connectivity-map.csv` — end-to-end cabling and port mapping (generated by DIET pipeline)
- `wiring/` — Hedgehog Wiring CRDs (cloned from air variant)
- `diagrams/hhfab/` — topology diagrams and hhfab validate logs (cloned from air variant)
- `netbox_inventory.json` — NetBox inventory export

## Notes

- Wiring topology is identical to the air-cooled variant. This directory carries its own generated artifacts for catalog completeness, not because the design differs.
- The `--liquid-8srv` suffix identifies liquid-cooled variants with an 8-server-per-unit rack density.
